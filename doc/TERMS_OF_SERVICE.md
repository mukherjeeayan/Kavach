## 5. Service Description

### 5.1 Core Features
Kavach provides the following parental control features:
- **App Blocking:** Block specific applications on your child's device
- **Screen Time Management:** Set daily screen-time limits and per-app usage caps
- **Location Tracking:** Real-time GPS tracking with location history
- **Geofencing:** Create safe zones with entry/exit alerts
- **Communication Monitoring:** SMS and call log monitoring with keyword-based cyberbullying detection
- **Emergency SOS:** One-touch emergency alert system
- **Device Health Monitoring:** Battery, storage, and security status
- **Mood Tracking:** Self-reported mood and wellness tracking
- **Multi-Device Support:** Manage multiple child devices from one dashboard
- **Co-Guardian Sharing:** Share child monitoring with another trusted adult

### 5.2 Service Limitations
- The App requires an active internet connection on the child's device
- Location accuracy depends on GPS signal and device capabilities
- App blocking requires Device Administrator privileges on Android
- The App does not guarantee 100% bypass prevention
- Real-time monitoring depends on device connectivity
- Some features may not be available on all Android versions
