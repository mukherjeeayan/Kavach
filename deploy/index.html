Step 2: Backend Configuration

Generating secure backend environment configuration with JWT secrets, database settings, and security parameters.

Leave empty to use in-memory rate limiting (development only).

What's Being Generated

  • JWT Secrets: 64-character cryptographically random strings for access and refresh tokens
  • Database Config: PostgreSQL host, port, user, database name, driver selection
  • Rate Limiting: Global (100/15min), Auth (5/15min), Per-device (10/min)
  • Security Headers: Helmet middleware configuration
  • .env file: Written to backend/ directory for Node.js server

Step 5: Admin Panel Setup

The admin panel is a separate app for managing users, subscriptions, and feature flags. It is hidden from end users and requires a shared access key.

How It Works

  • An ADMIN_ACCESS_KEY is shared between the backend and admin panel
  • Non-admin users are blocked at the route level in the main frontend
  • Admin users access it via a triple-click on the logo in the header
  • The admin panel won't load without the access key configured

Default is 5174 to avoid conflicts with the main frontend (5173).

This email will be pre-configured as the first admin. You'll register this account after deployment.

What's Generated

  • ADMIN_ACCESS_KEY: Added to backend .env (auto-generated 64-char secret)
  • VITE_ADMIN_ACCESS_KEY: Added to admin-panel .env (same key)
  • VITE_API_URL: Backend API URL for the admin panel
  • Admin panel included in the deploy script (npm install + npm run dev)

Security Checklist

  • JWT secrets are 64-character random strings (kept secure, not committed to git)
  • ADMIN_ACCESS_KEY shared between backend and admin-panel (auto-generated)
  • ALLOWED_ORIGINS set to your production domain(s)
  • Mapbox token restricted by domain in Mapbox dashboard
  • HTTPS/SSL configured at reverse proxy/load balancer level
  • Android certificate pins match production server certificate
  • google-services.json placed in android/app/ if Firebase/FCM enabled
  • Admin panel deployed on a separate port/subdomain, not publicly linked
