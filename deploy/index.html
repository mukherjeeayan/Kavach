Next Steps

  1. Backend: Place generated .env in kavach/backend/ directory. Run cd backend && npm install && npm run db:migrate
  2. Frontend: Place generated .env in kavach/frontend/ directory. Run cd frontend && npm install then npm run dev
  3. Android: Open in Android Studio. Build -> Build Bundles / APK(s) -> Build Bundle(s). For release, provide certificate pins via gradle: ./gradlew assembleRelease -PSAFEGUARD_PINS="pins"
  4. Database: Ensure PostgreSQL is running with credentials from the .env file (user: postgres, password: password, db: safeguard)

Security Checklist

  • ✅ JWT secrets are 64-character random strings (kept secure, not committed to git)
  • ✅ ALLOWED_ORIGINS set to your production domain(s)
  • ✅ Mapbox token restricted by domain in Mapbox dashboard (never baked into frontend)
  • ✅ Redis configured for production rate limiting (or in-memory fallback documented)
  • ✅ HTTPS/SSL configured at reverse proxy/load balancer level
  • ✅ Android certificate pins match production server certificate
  • ✅ google-services.json placed in app/ if Firebase/FCM enabled

Need Help?

If you encounter issues:

  • Ensure Node.js 18+ is installed for backend
  • Ensure Python/pip is available for database migrations
  • Android Studio Ladybugbee (2024.1.1) or newer recommended
  • PostgreSQL 16+ recommended for production
