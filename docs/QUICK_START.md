# Kavach - Quick Start Guide

## 🎯 One-Click Deployment - No Manual Copying!

Follow these 3 steps. Total time: 3-5 minutes.

---

## Step 1: Run the Wizard 🧙‍♂️

**Open:** `deploy/index.html` in your web browser

**Do this:**
1. Double-click the file `deploy/index.html` in the Kavach folder
2. Wait for it to load in your browser
3. Follow the 5-step wizard (Environment, Backend, Frontend, Android)

**Result:** A deployment script is generated automatically.

---

## Step 2: Download & Run the Script 🚀

**Do this:**
1. Click **Download Script** in the wizard (Step 5)
2. Open a terminal in the Kavach folder
3. Run the script:

**Linux/macOS:**
```bash
chmod +x deploy.sh
./deploy.sh
```

**Windows:**
```cmd
deploy.cmd
```

The script handles everything: installs dependencies, sets up the database, builds the frontend, and verifies all services.

---

## Step 3: Build Android 📱

After the script completes, build the Android app:

```bash
cd android
./gradlew assembleDebug    # Linux/macOS
gradlew.bat assembleDebug  # Windows
```

Or open `android/` in Android Studio and click Run.

---

## 🔑 Security Reminders

✅ **DO** save the JWT secrets (64-char strings) somewhere secure  
✅ **DO** keep your Mapbox token restricted by domain in the Mapbox dashboard  
✅ **DO** not share JWT secrets via email, chat, or social media  
✅ **DO** keep ALLOWED_ORIGINS set to your actual domain(s)  

❌ **DON'T** commit .env files to GitHub or any version control  
❌ **DON'T** share JWT secrets with anyone  
❌ **DON'T** bake the Mapbox token into the frontend bundle permanently

## 🆘 Having Issues?

| Problem | Quick Fix |
|---------|-----------|
| "PostgreSQL connection failed" | Ensure Docker is running OR PostgreSQL service is started. Default: user=postgres, password=password, db=kavach |
| "Module not found" errors | Run `npm install` in the respective directory |
| "Map not showing" | Get Mapbox token from mapbox.com, restrict by domain |
| "Android build fails" | Open Android Studio, ensure google-services.json is in android/app/ |
| "Socket.io not connecting" | Ensure both backend (`npm run dev`) and frontend (`npm run dev`) are running |
