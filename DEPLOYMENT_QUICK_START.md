# Kavach - 3-Minute Quick Start Guide

## 🎯 One-Click Deployment - No Manual Copying!

Follow these 3 steps. Total time: 3-5 minutes. **All configuration files are generated automatically.**

---

## Step 1: Run the Wizard 🧙‍♂️

**Open:** `deploy/index.html` in your web browser

**Do this:**
1. Double-click the file `deploy/index.html` in the Kavach folder
2. Wait for it to load in your browser
3. Follow the 5-step wizard

**Choose your mode:**
- **Development** - Easiest, uses localhost (recommended first time)
- **Production** - For live use with your own domain
- **Local** - Docker/local testing

**Follow prompts:** Answer the questions (mode, domain, a few options)

**Result:** Configuration files are generated automatically - **no copying needed!**

---

## Step 2: Verify Files Were Created ✅

The wizard automatically writes all configuration files to the correct locations:

| File | Auto-Placed In |
|------|---------------|
| **Backend .env** | `kavach/backend/.env` |
| **Frontend .env** | `kavach/frontend/.env` |
| **Android BuildConfig** | `app/obj/BuildConfig.cs` |

**Check these files** - they contain your complete configuration. No manual copy/paste required!

**Quick verification:**
```bash
# Backend .env should exist and have JWT secrets
type kavach/backend\.env | findstr JWT

# Frontend .env should exist
type kavach/frontend\.env

# Android BuildConfig should exist
type app\obj\BuildConfig.cs
```

---

## Step 3: Run the Servers 🚀

**Backend:**
```bash
cd kavach/backend
npm install           # First time only
npm run db:migrate    # Set up database
npm run dev           # Start the server
```
- Server runs at: `http://localhost:3000`

**Frontend (Web Dashboard):**
```bash
cd kavach/frontend
npm install           # First time only
npm run dev           # Start the dashboard
```
- Dashboard at: `http://localhost:5173`
- Open your browser to this address

**Android App:**
```bash
# Open Android Studio
# Then: Build -> Build Bundles / APK(s) -> Build Bundle(s)
```

---

## 🔑 Security Reminders

✅ **DO** save the JWT secrets (64-char strings) somewhere secure  
✅ **DO** keep your Mapbox token restricted by domain in the Mapbox dashboard  
✅ **DO** not share JWT secrets via email, chat, or social media  
✅ **DO** keep ALLOWED_ORIGINS set to your actual domain(s)  

❌ **DON'T** commit .env files to GitHub or any version control  
❌ **DON'T** share JWT secrets with anyone  
❌ **DON'T** bake the Mapbox token into the frontend bundle permanently

## 🆘 Having Issues?

| Problem | Quick Fix |
|---------|-----------|
| "PostgreSQL connection failed" | Ensure Docker is running OR PostgreSQL service is started. Default: user=postgres, password=password, db=safeguard |
| "Module not found" errors | Run `npm install` in the respective directory |
| "Map not showing" | Get Mapbox token from mapbox.com, restrict by domain |
| "Android build fails" | Open Android Studio, ensure google-services.json is in app/ |
| "Socket.io not connecting" | Ensure both backend (`npm run dev`) and frontend (`npm run dev`) are running |
